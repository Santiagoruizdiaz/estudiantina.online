# Integrations Context — Estudiantina.online

## External Services & Client Libraries
1. **Google Identity Services (GSI)**:
   - SDK: `https://accounts.google.com/gsi/client`
   - Uso: Autenticación de un solo clic para que los estudiantes debatan en el foro sin registrar contraseñas manuales.
2. **html2canvas**:
   - CDN: `https://cdnjs.cloudflare.com/ajax/libs/html2canvas/1.4.1/html2canvas.min.js`
   - Uso: Renderizado de la Ficha de Egresado (Card FIFA) directamente en el navegador del cliente para guardarla como imagen PNG de alta fidelidad y compartirla en Instagram / WhatsApp.
3. **Google Fonts CDN**:
   - Tipografías `Outfit`, `Inter`, `Plus Jakarta Sans` cargadas con optimización `display=swap` y `rel=preconnect`.
4. **Hostinger LiteSpeed Server**:
   - Servidor web con compresión Gzip nativa, reglas `.htaccess` de seguridad y certificados SSL automáticos.
